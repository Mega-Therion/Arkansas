# Natural State UI design mockups

These two generated images are concept-only visual references, not production UI or data. I reviewed both at desktop and mobile sizes; their sample readings and statuses are illustrative, not USGS measurements. The desktop concept includes a legacy-looking source URL as nonfunctional sample text—use only the live site's documented Water Data APIs v1 link for real source navigation. The images are stored in the project's managed storage and are not imported as application UI.
