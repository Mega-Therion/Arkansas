local trust rather than outrunning it:

**Segment → Authenticate → Consent → Tune → Promote Slowly → Power-Down.**

This is the system-facing half of the portfolio's philosophy. The **Diamond Foundation** (see
[`../wholonomy/diamond-foundation.md`](../wholonomy/diamond-foundation.md)) is its citizen-facing
counterpart — the state stands in front of the citizen and the structure stays legible; Gentle
Authority is how the Orchard governs itself so it never becomes the thing it replaced.

## foundRY's three working products (from the Wholonomy, Part VIII)

1. **Rights-and-Evidence Registry.** Per project: land rights, liability, assay, permits, public funds received, worker obligations, revenue waterfall, exit conditions.
2. **Phase-gated options.** A time-limited right to characterize an asset, which ends automatically if the assay, permits or offtake fail.
3. **Public-benefit covenant.** Any project that takes state money first carries local-hiring minimums, public data access, reclamation security and a repayment trigger, and the covenant travels with the project.
