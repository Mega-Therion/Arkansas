# ConservatoRY: the give-back arm

**Status:** concept from a December 2025 conversation (`20_Sources/ChatGPT/2025-12/S_Corp_vs_C_Corp.md`). No entity has been formed.

Most overviews of the Orchard dropped this piece. It is the nonprofit **fruit of the tree**: what the commercial branches give back to the places they grow in.

RY, verbatim (December 2025):

> "Remember I wanted the tree planting initiative to be in that branch and it was called the ConservatoRY."

## Names: real words only

In that same thread RY set a constraint: every -RY name has to be a **real word**. That ruled out the assistant's invented suggestions ("ArboRY", "ScholarRY", "StewardRY", "CommunitRY"), and the assistant withdrew them. The structure that survives the constraint:

| Name | Role |
|---|---|
| **ConservatoRY** (Conservatory) | 501(c)(3) umbrella: conservation, land stewardship, education |
| **ForestRY** (Forestry) | Tree planting: reclamation plantings on recoveRY sites, community canopy |
| **TreasuRY** (Treasury) | The scholarship fund |

The stylized spellings of Forestry and Treasury above follow the house pattern. The thread itself spells them plainly. ConservatoRY is also the name of the Diamond Foundation test every branch must pass (see the README tree).

## Timing

As recorded, the nonprofit forms *after* operations are stable and a revenue node exists, so it isn't the first cash engine. The top-down architecture puts it at Phase 5.

## Where it closes the loop

recoveRY takes on a damaged site → refineRY and factoRY use what's in it → ForestRY plants the reclaimed ground → libraRY's Process Passport records that the cleanup stayed a cleanup.
